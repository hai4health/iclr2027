# HAI4Health: Human-Centered AI for Health @ ICLR 2027

Website for the ICLR 2027 workshop **Human-Centered AI for Health**.
Live site: https://hai4health.github.io/iclr2027/

## Updating the site

- All content lives in `index.html` (speakers, agenda, call for papers, organizers, footer).
- Site-specific styling is in `styles/css/site.css`. The other files in `styles/` are the shared template and should not be edited by hand.
- Photos go in `public/data/images/{speakers,organizers,advisory}/` as 3:4 portrait JPEGs (600x800 works well).
- The hero background is `public/hero.jpg` (16:9) and `public/hero-mobile.jpg` (portrait); `public/social-card.jpg` is the link-preview image.
- Pushing to `main` redeploys the site through GitHub Pages within a minute or two.
